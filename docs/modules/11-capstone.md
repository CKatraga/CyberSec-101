# M11 · Capstone <span class="week-pill">Week 16</span>

**Goal:** prove to yourself that it all connects. You'll run a small end-to-end engagement against a legal target and write it up like a professional.

*Reinforces: everything. This is your portfolio piece.*

## The challenge

Pick **one** track (or do both if you're on fire):

=== "Track A — Mini penetration test"

    Against **Metasploitable 2** or a beginner **TryHackMe/HTB** box:

    1. **Recon & scan** (Module 2, 7).
    2. **Find and exploit** at least one vulnerability to get a shell (Module 7).
    3. **Escalate or pivot** if you can (bonus).
    4. **Write a report** using the template below.

=== "Track B — Web app assessment"

    Against **OWASP Juice Shop**:

    1. Solve **at least 10** challenges across different OWASP categories (Module 6).
    2. For 3 of them, document the vulnerability, the exploit, and the fix.
    3. **Write it up** as a findings report.

## The report (this is the real deliverable)

Employers hire people who can **communicate** findings. Write a 3–5 page report with:

- **Executive summary** — what you tested, top findings, in plain English.
- **Scope & methodology** — what was in scope, tools used.
- **Findings** — each with: severity (use CVSS), description, evidence (screenshot), and remediation.
- **Conclusion** — overall risk posture and next steps.

Save it as `journal/capstone-report.md` and commit it. This goes in your portfolio.
