# Roadmap — 16 weeks

A realistic path from "I read to pass" to "I can actually do this." Each module maps to subjects you already touched at AUM, so it reinforces your degree instead of competing with it.

| Week | Module | Focus | Where you work |
|---|---|---|---|
| 1 | [M1 Terminal & Bash](modules/01-bash.md) | Live in the Linux terminal | Cloud workspace |
| 2 | [M1 Terminal & Bash](modules/01-bash.md) | Bash CTF + scripting | Cloud workspace |
| 3 | [M2 Networking](modules/02-networking.md) | How data moves; TCP/IP, ports, DNS | Cloud workspace |
| 4 | [M2 Networking](modules/02-networking.md) | nmap, packets, subnetting | Cloud workspace |
| 5 | [M3 Python for Security](modules/03-python.md) | Automate tasks; write small tools | Cloud workspace |
| 6 | [M4 Security+ Foundations](modules/04-security-foundations.md) | Core security vocabulary & concepts | Anywhere (video) |
| 7 | [M4 Security+ Foundations](modules/04-security-foundations.md) | Threats, controls, risk | Anywhere (video) |
| 8 | [M5 Cryptography](modules/05-crypto.md) | Hashing, symmetric/asymmetric, TLS | Cloud workspace |
| 9 | [M6 Web Security](modules/06-web.md) | OWASP Top 10, Burp, SQLi, XSS | Cloud + Juice Shop |
| 10 | [M6 Web Security](modules/06-web.md) | Guided PortSwigger labs | Browser |
| 11 | [M7 Kali & Pen Testing](modules/07-pentest.md) | Install Kali; recon → exploit | **Kali VM** |
| 12 | [M7 Kali & Pen Testing](modules/07-pentest.md) | Full box walkthroughs (TryHackMe) | Kali VM |
| 13 | [M8 Network Security](modules/08-network-security.md) | Wireshark, firewalls, IDS | Kali VM |
| 14 | [M9 Malware & Forensics](modules/09-forensics.md) | Triage, Windows artifacts, logs | Kali VM / FlareVM |
| 15 | [M10 Privacy & Governance](modules/10-privacy-governance.md) | Data privacy, GRC, cloud, Zero Trust | Anywhere |
| 16 | [M11 Capstone](modules/11-capstone.md) | Mini-pentest report + CTF finale | Kali VM |

!!! note "Two phases"
    **Weeks 1–10 (browser only):** everything runs in a free cloud workspace — no install pain.
    **Weeks 11–16 (Kali):** you switch to a real attacker machine for tools that need a full OS. Pranith helps you set this up in Week 11.
